# Live Incident Response | Linux Incident Investigation

**Proyecto final de Ciberseguridad — 4Geeks Academy | Agosto 2026**

## Descripción

Investigación académica de un incidente de seguridad simulado en un sistema Ubuntu 20.04.6, aplicando técnicas de respuesta a incidentes en vivo (*Live Incident Response*).

El proyecto consistió en analizar procesos, registros del sistema, usuarios, conexiones de red y scripts para identificar actividades sospechosas, documentar evidencias y proponer medidas de mitigación.

## Principales hallazgos

Durante la investigación se identificaron y clasificaron **8 hallazgos de seguridad**, entre ellos:

- Mecanismos de persistencia mediante tareas programadas con cron.
- Credenciales almacenadas de forma insegura.
- Actividad sospechosa relacionada con accesos SSH.
- Scripts y conexiones compatibles con una posible exfiltración de información.

## Competencias aplicadas

Análisis de incidentes · Linux · Investigación de registros · Análisis de procesos · Persistencia · Identificación de indicadores de compromiso · Documentación técnica · Recomendaciones de seguridad
